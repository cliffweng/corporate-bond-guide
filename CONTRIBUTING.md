# Contributing

PRs welcome for typos, clearer explanations, and verified YouTube/docs links.

## Guidelines

- Keep each topic readable in ~10 minutes.
- Verify every YouTube URL with GET oEmbed before adding; never invent links.
- Match the existing topic shape.
- **MathJax delimiters**: double-escape for kramdown — write `\\(` `\\)` `\\[` `\\]` in source so HTML keeps `\(` `\)` `\[` `\]`. Escape subscripts as `\_` (e.g. `r\_d`, `y\_TM`).
- Prefer trailing-slash relative links (`../03-duration-convexity/`), not `.html`.
- Bias toward credit/FI desk interview rigor.

Open a draft PR against `main`. Thanks!
